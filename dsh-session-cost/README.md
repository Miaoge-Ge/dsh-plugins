# 用量与消费 · DeepSeek Harness

一个本地用量仪表盘。查看今日消费、账户余额、历史月份、每个模型的费用和 token 分项，并保留输入框下的会话费用入口。

## 功能

- **今日 / 月度 / 全部 / 本会话**：按北京时间切分日期，可切换历史月份；首屏即今日消费与调用量。
- **账户余额**：通过 Harness 原生、已鉴权的账户接口读取当前登录账户的充值和赠送余额，桌面版与 Web 版使用同一通道；插件不接触 API Key。
- **模型费用明细**：按 provider 与 model 分组，展示未缓存输入、缓存读取、缓存写入、输出 tokens 及对应金额。
- **网页检索计费**：`web_search` / `web_fetch` 按 5 元 / 1000 次成功请求计入（每次 ¥0.005），失败与取消的调用不计。
- **今日分时**：今日视图下给出 24 小时消费柱图与分时明细表。
- **月度趋势**：逐日消费柱图，可展开每日金额、tokens、调用次数表格。
- **缓存命中率**：缓存读取 / 全部输入 tokens。
- **CSV 导出**：导出当前范围的模型汇总，包含调用次数、token 分类、金额、待计价及不完整调用数。
- **自定义模型单价**：填写其他厂商模型的人民币单价，原生设置持久化。
- 每分钟自动刷新，也可手动刷新。内存缓存只保留计量元数据；后续读取仅补充新增日志页。

入口：**账号菜单 → 设置 → 用量与消费**，或点击会话输入框下的消费统计。

## 安装与开发

需要 DeepSeek Harness 0.2.2-rc.1 或兼容版本、Node.js 20+。

```powershell
# 在合集仓库根目录执行
npm.cmd ci --ignore-scripts
npm.cmd run check
dsh plugin --profile desktop add "C:\path\dsh-plugins\dsh-session-cost"
```

完全退出并重新打开 Harness。源码通过目录链接加载，修改后运行 `npm.cmd run build`，再重新打开应用。生产客户端复用宿主 React，无 CDN 或独立 React。账户余额由宿主通过其官方账户服务读取。

可运行 `npm.cmd pack` 生成安装包；卸载：`dsh plugin --profile desktop remove @local/session-cost`。

## 计量口径

读取有权限访问的持久会话日志，逐次调用按实际 provider/model、实际 token 用量与调用开始时刻计价。最终用量替换同一次尝试的中间样本，重试分别统计；分叉继承的历史不重复计费。分页读取固定日志截止点，不依赖当前打开的聊天页，也不以当前所选模型回算整段会话。取消、失败但已报告用量的尝试也计入；缺少完整用量的尝试单独标记。

内置 **2026-11-07 官方价格快照**（元 / 百万 tokens）：

| 模型 | 高峰缓存命中 | 高峰未缓存输入 / 缓存写入 | 高峰输出 |
| --- | ---: | ---: | ---: |
| DeepSeek Flash | 0.04 | 2 | 8 |
| DeepSeek V4 Pro | 0.30 | 9 | 27 |

空闲时段半价。北京时间周一至周五 09:00–12:00、14:00–18:00 为高峰，周末及节假日为空闲。内置 2026 年放假日期，其他年份仅识别周末，需更新节假日表。Flash 旧别名映射到官方 Flash 价格；仅对 `deepseek`、`deepseek-account`、`deepseek-official` 路由默认计价。

价格来源：[DeepSeek 官方模型价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。2026 年节假日来源：[国务院办公厅通知](https://www.beijing.gov.cn/cs/gncs/zcwj/202603/t20260327_4568275.html)。历史记录也按上述价格快照回算，无法还原历次调价。

金额按上表价格快照与日志用量估算；成功完成的内置 Search / Fetch 调用按次单列。标题生成等未记入此类会话记录的调用、其他客户端用量及历史价格调整均可能造成与官方账单的差别。已删除、不可访问和需迁移的会话不会被静默算成完整统计；页面会报告读取失败数量。无单价的模型保留 token 数，并显示待计价，金额合计仅包含可计价部分。

### 自定义价格

在页面底部展开“自定义模型单价”，填写 `provider/model` 对应的四项单价。例如下面只是格式示例，需填入实际单价：

```json
{
  "your-provider/your-model": {
    "input": 1,
    "cacheRead": 0.1,
    "cacheWrite": 1,
    "output": 2
  }
}
```

单位统一为人民币 / 百万 tokens，自定义价格不再乘峰谷系数；保存后对全部历史重新计价。输入 `{}` 可恢复内置价格。原生设置服务负责持久化，写入失败会明确提示。

## 隐私与验证

插件只通过 Harness 的既有权限接口读取会话。内存里保留时间、模型、token 数和日志位置，不保存正文、工具内容、凭据，也不把个人账单、会话日志上传至仓库。CSV 仅在主动点击时下载。

余额使用 Harness 原生 `account.getBalance` 接口，每两分钟更新一次，也可手动刷新。未登录 Harness 账户、权限不足或网络失败时显示“—”，不影响用量统计。API Key 所属账户可能与 Harness 登录账户不同，余额明确属于当前登录账户。不同币种分开计算。

`npm.cmd run check` 检查构建、语法和计量单元测试，包括跨日、峰谷、混合模型、重试替换、分叉去重、未知价格、自定义价格、分页、增量缓存和连接错误。已在 Windows / Harness 0.2.2-rc.1 的真实 Web 宿主验证历史记录读取、月度切换、CSV 下载以及 390px 窄屏，无页面错误。默认界面文案为中文。

源码：`src/accounting.mjs` 纯计量逻辑，`src/loader.mjs` 分页读取，`src/client.js` 界面，`src/style.css` 样式；`client.js` 由构建生成。

## 0.0.1 合集版优化

网页检索只有成功结算后才计入费用，未完成和失败调用不计；纯检索记录不生成空白模型行。余额读取复用已鉴权的原生通道，兼容桌面版并正确区分人民币与美元。
