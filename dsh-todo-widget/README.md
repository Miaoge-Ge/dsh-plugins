# 每日待办 · Daily to-dos

内嵌在 DeepSeek Harness 里的每日待办：侧边栏点开是一整页清单，输入框下方有一条今日进度快捷条，到点没做完会弹出提醒。没有独立悬浮窗，配色全部走 DSH 主题令牌，深色模式与宿主一致。

## 在哪里

| 入口 | 说明 |
| --- | --- |
| 侧边栏「每日待办」 | 打开整页待办；图标与选中态沿用侧边栏自己的样式 |
| 输入框下方快捷条 | 显示「今日待办 2/5」，逾期时标红；点一下打开整页 |
| 到点提醒 | 右上角的临时提醒卡，不是常驻窗口 |

## 怎么用

- **添加**：页面顶部输入框（打开页面即聚焦），回车或点「添加」。点输入框右侧时钟可同时设提醒时间。
- **完成**：每行左侧方框；勾选后记下「完成于 10:24」，点该时间可改。
- **编辑**：双击文字或点行尾铅笔；垃圾桶删除。
- **按天**：日期行 ‹ › 翻看，当天标为「今天」，离开今天后出现「回到今天」。昨天没做完的仍留在昨天。
- **昨天未完成**：今天页面顶部会出现提示条，可「查看昨天」或一键「移到今天」（移到今天后提醒时间需要重设）。
- **提醒设置**：页面底部的「提醒设置」可改每日收尾时间、关闭，或关掉输入框下方的快捷条。

## 提醒规则

1. **单条提醒**：给某条待办设了提醒时间，到点仍未完成就弹提醒。
2. **每日收尾**：默认 18:00（可改/可关）；到点后若今天或最近 3 天还有未完成，弹一次。
3. 提醒卡里「知道了」当天不再重复；「稍后 10 分钟」10 分钟后再提。
4. 提醒只在 Harness 页面打开时出现（不发系统通知）。

## 数据与隐私

- 待办保存在本机浏览器 localStorage，按天记录、最多 400 天；不读会话、不写 `cordis.patch.yml`、不联网。
- 同一来源下多个窗口通过 `storage` 事件同步；写入失败时页面会提示。
- 清除浏览器站点数据会同时清除待办。

## 安装

```powershell
dsh plugin --profile desktop add "C:\path\to\dsh-todo-widget"
```

仓库根目录的 `.\scripts\install.ps1` 会把本插件和其他三个插件一起链接进来。

## 开发

```powershell
npm.cmd run build   # 把 src/model.mjs、src/style.css 与 locale 内联为 client.js
npm.cmd test        # 模型单测 + 客户端渲染冒烟测试
npm.cmd run check   # 构建、语法检查与测试
```

`client.js` 是构建产物，修改请改 `src/`。纯逻辑（日期、排序、提醒判定）在 `src/model.mjs`，可脱离浏览器测试。

## 已知限制

- 提醒依赖页面处于打开状态，没有系统通知或托盘图标。
- 只有一次性待办，不做重复任务、子任务、标签与多设备同步。
- 页面按天保存，不做周视图或统计图表。
